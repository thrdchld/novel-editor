# Manuscript Technical Audit

## Ejaan dan bahasa objektif
- [ ] Typo dan salah ketik.
- [ ] Ejaan baku dan bentuk gabungan.
- [ ] Imbuhan, kata depan, kata ulang, kapitalisasi.
- [ ] Penulisan angka, tanggal, waktu, gelar, singkatan.
- [ ] Tata bahasa yang rusak hingga mengaburkan makna.
- [ ] Rujukan kata ganti dan subjek/pelaku jelas.
- [ ] Variasi bahasa lisan yang disengaja tidak salah ditandai.

## Tanda baca dan tipografi
- [ ] Tanda kutip dialog dan tanda baca akhir.
- [ ] Koma, titik dua, titik koma, elipsis, kurung, dash.
- [ ] Konsistensi tanda baca sesuai hard rules proyek.
- [ ] Tidak ada penggantian massal tanpa pemeriksaan konteks.

## Konsistensi istilah
- [ ] Nama karakter dan variasi nama panggilan.
- [ ] Nama tempat, organisasi, institusi, jabatan, gelar.
- [ ] Istilah dunia, istilah teknis, singkatan.
- [ ] Angka/fakta yang berulang tidak saling bertentangan.

## Struktur dan Markdown
- [ ] Semua bab memiliki heading yang berfungsi.
- [ ] Tidak ada nomor bab hilang/duplikat tanpa alasan.
- [ ] Batas bab dan pemisah adegan benar.
- [ ] Paragraf tidak salah terbungkus italic/bold/code.
- [ ] Markup dan code fence tertutup.
- [ ] Tidak ada catatan editor, komentar kerja, TODO, FIXME, atau placeholder tertinggal.
- [ ] Tidak ada teks duplikat akibat copy-paste.

## Orientasi dan fakta domain
- [ ] Flashback/lompatan waktu memiliki cue yang cukup dan alami.
- [ ] Posisi tokoh/benda serta urutan aksi fisik dapat diikuti.
- [ ] POV tidak bocor ke pikiran/informasi tokoh lain tanpa penanda.
- [ ] Prosedur/fakta dunia nyata yang material telah diverifikasi dari sumber tepercaya atau ditandai REVIEW.

## Dialog dan atribusi
- [ ] Pembicara dan atribusi dialog tidak tertukar.
- [ ] Tanda kutip dan pergantian pembicara dapat diikuti.
- [ ] Pengetahuan dalam dialog sesuai dengan informasi yang dimiliki tokoh.

## Batas artistik
- [ ] Tidak menilai tone, gaya, voice, diksi, humor, atau keindahan prosa.
- [ ] Tidak mengubah kalimat yang hanya berbeda preferensi.
- [ ] Rekomendasi hanya untuk kesalahan teknis objektif atau kebingungan faktual.
